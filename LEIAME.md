# Vídeo Wallpaper (Android)

## Gerar o APK
Opção A, Android Studio: File > Open nesta pasta, aguarde a sincronização e use Build > Build APK(s).
O arquivo sai em app/build/outputs/apk/debug/app-debug.apk.

Opção B, sem instalar nada: crie um repositório no GitHub, envie estes arquivos e abra a aba Actions.
O workflow "Build APK" gera o app-debug.apk para download.

## Instalar
Copie o APK para o celular, permita "instalar apps desconhecidos" e abra o app.
